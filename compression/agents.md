## API Classes Used
- `ZipArchive` — represents a ZIP archive; allows opening, adding entries, and saving.  
- `CabArchive` — creates and saves CAB archives; supports stream providers and entry options.  
- `LzipArchive` — handles LZIP compression; lets you set source file and save the archive.  
- `XzArchive` — handles XZ compression; lets you set source file and save the archive.  
- `SevenZipArchive` — creates 7z archives; works with specific compression settings.  
- `SevenZipLzma2CompressionSettings` — configures LZMA2 compression parameters such as thread count.  
- `CreateEntry` (method of `ZipArchive`) — creates a new entry in the ZIP archive from a stream or file.  
- `SetSource` (method of archive classes) — specifies the input file to be compressed.  
- `Save` (method of archive classes) — writes the constructed archive to disk.  
- `SetCompressionThreads` (method on compression settings) — defines how many threads to use during compression.  
- `SetDictionarySize` (method on LZIP settings) — adjusts the dictionary size for LZIP compression.

## Developer Q&A

### Q: How can I add multiple files to an existing ZIP archive from streams in C# using Aspose.ZIP?
Use `ZipArchive.Open` to open the existing ZIP, then call `CreateEntry` for each file and copy the source stream into the entry’s `OpenWrite` stream. → See: `add-entries-to-a-zip-archive-by-opening-source-files-with-openread-and-creating-entries-via-createentry.cs`

### Q: How do I add a FileStream to a ZIP archive and automatically close the source stream after saving with Aspose.ZIP for .NET?
Add the file with `archive.AddEntry(entryName, fileStream)` and save the archive using `SaveOptions` where `CloseEntrySource = true`. → See: `add-entry-to-zip-from-a-local-filestream-set-closeentrysource-true-in-the-format-specific-save-options-save-auto.cs`

### Q: How can I create a CAB archive from two XML files using stream providers in Aspose.ZIP?
Create a `CabArchive`, add `CabArchiveEntry` objects that use a `StreamProvider` delegate to supply each XML file stream, then call `Save`. → See: `build-cab-archive-with-entries-from-two-local-xml-files-using-stream-providers-and-automatic-disposal-save-xml-cab.cs`

### Q: How do I set a custom dictionary size and number of compression threads for an LZIP archive in C# with Aspose.ZIP?
Instantiate `LzipArchiveSettings`, set `DictionarySize` and `CompressionThreads`, and pass the settings to `LzipArchive.Save`. → See: `configure-lzip-archive-with-custom-dictionary-size-and-compressionthreads-three-compress-dataset-xml-to-dataset-lz.cs`

### Q: How can I compress a large video file into a 7z archive using Aspose.ZIP with a specific number of compression threads?
Create a `SevenZipArchive`, configure `SevenZipLzma2CompressionSettings.CompressionThreads` to the desired count, add the video entry, and save the archive. → See: `create-a-7z-archive-from-one-5-gib-video-file-configure-sevenziplzma2compressionsettings-compressionthreads-to-12.cs`
