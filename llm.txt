## About Aspose.ZIP for .NET

Aspose.ZIP for .NET is a UI-agnostic backend API for archive processing that integrates
into any .NET application — ASP.NET Core, console apps, Azure Functions, Docker containers,
and microservices — without requiring a display, desktop, or UI framework.

## What Makes These Examples Different

- Every example is compiled and runtime-verified before publishing
- Each example includes real-world use cases (developer and AI agent friendly)
- Generated by an AI agent with 3-attempt validation pipeline
